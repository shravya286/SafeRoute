# AbhayaSetu (अभयसेतु) — SafeRoute Bridge

A safety advisory web application that transforms natural-language safety questions into verified, evidence-backed risk assessments using live weather and earthquake data feeds.

## Project Structure
- `backend/`: Node.js + Express backend API with Open-Meteo & USGS seismic data integrations.
- `frontend/`: React + Vite mobile-first responsive frontend adhering to the minimal flat design system.
